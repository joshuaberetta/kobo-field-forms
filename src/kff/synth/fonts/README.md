Handwriting-style fonts for synthetic filled-in sheets (tests and `kff e2e` only; never
in printed PDFs). All SIL Open Font License 1.1 (`OFL.txt`), from github.com/google/fonts
(`ofl/<family>/`), fetched 2026-10-29: Patrick Hand, Indie Flower, Kalam, Gochi Hand
(Latin), Aref Ruqaa (Arabic).

They are much tidier than real handwriting, so accuracy measured on synthetic sheets is
an upper bound. Keep them out of recogniser training data, or the test measures the
training set.
